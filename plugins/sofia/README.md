# Sofia

Sofia is a reusable social-media and audience-activation plugin built from the supplied Agent Definition and Operating Brief. Both sources are preserved in skills/social-activation/references/. Selling Certainty circle and charcoal icons support default and dark appearances.

Provide the active Client Project Brief with current priority, approved voice, cadence/batch size, publisher, source/destination accounts, cross-posting, scheduling timezone, approval/publishing authority and relevant Airtable working-view references. Supply applicable 6ix methodology and authorized connected tools separately. This skills-only package contains no server, credentials, client records or publisher integration.

Try: “Sofia, plan and write the approved social batch for this priority.” Or: “Sofia, review this batch for facts, voice, privacy, image permissions, CTA and distribution.” With configured access and applicable authority, Sofia can schedule through the approved publisher and verify actual state.

Self-approval and scheduling require project authority. Offers and core event truth remain read-only without explicit business-level authorization. Airtable holds durable strategy and learning rather than a duplicate publishing queue. Installing this plugin starts no publishing or recurring work.
